# Free-tier AI status

The Ask endpoint is implemented with Cloudflare Workers AI and the `@cf/meta/llama-3.2-3b-instruct` model. It only summarizes matches retrieved from the server's public organization, event, and guidance records. Reimbursement uploads and private financial data remain in the browser and are not sent to this model.

The deployment fails closed unless it can verify the account's free subscriptions before every inference. It also reserves against a persistent limit of 100 model calls per UTC day, limits each prompt to 4,096 bytes and each response to 128 tokens, and falls back to public-record search if any check or model call fails. Cloudflare documents a 10,000-neuron daily allocation on the Workers Free plan, after which requests fail rather than bill; the app's call cap is an additional guard, not a conversion of calls into neurons. See [Workers AI pricing](https://developers.cloudflare.com/workers-ai/platform/pricing/) and [free-allocation errors](https://developers.cloudflare.com/workers-ai/platform/errors/).

**Live status on September 29, 2026:** the Cloudflare dashboard shows a Free plan, but `CF_BILLING_READ_TOKEN` has not been provisioned as a Worker secret. A production `/api/ask` check returned `{"mode":"rules","reason":"free_plan_unverified"}`. Therefore, the site currently serves search results without a model summary. This is intentional until the runtime can verify the billing status.

Activation requires a Cloudflare API token scoped to this account with **Account > Billing > Read**, supplied only as the Worker secret `CF_BILLING_READ_TOKEN`. Do not put the token in Git, `wrangler.jsonc`, client-side code, or a chat message. Cloudflare's [billing permission guide](https://developers.cloudflare.com/billing/understand/billing-permissions/) and [subscriptions endpoint](https://developers.cloudflare.com/api/resources/accounts/subresources/subscriptions/methods/get/) describe the required scope. After setting the secret, make one test Ask request and confirm `mode: "ai"`; a `mode: "rules"` result means the summary is still unavailable. Never bypass the verification gate to make a test pass.
